Change the loading, gel thickness, retention and proteolysis rate. The page re-runs the same gel–tissue solver as the figures in your browser (it agrees with the Python solver to within 1 %). The treatment-protocol sliders then simulate wound closure for the patch-change schedule you pick. Note that closure is a threshold: past the longest workable interval shown below, no wound closes at any size, so both protocol sliders stop changing the closure time and report the duty-cycle shortfall instead.

Read this before trusting a slider. A one-parameter-at-a-time sweep can only reach the first-order share of the variance (37 % for delivered dose, Figure 10); every interaction between parameters is invisible here, so this is a presentation tool and not a sensitivity analysis. The longest workable change interval does not depend on wound size: whether a wound closes at all is set by whether the time-averaged drug effect keeps cells growing faster than they die, which is the same everywhere in the wound bed. Wound size sets how long closure takes. Both outputs rest on Tier-4 closure parameters and a scenario treated state (FGF2-G3 at EC50, V14 at ψ50). The loading slider is the total dose; only frel = 0.5 of it is mobile and reaches tissue. 3 mg/mL is the largest loading the team has dissolved, so values above it assume a solubility that has not been measured.
